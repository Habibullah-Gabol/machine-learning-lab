## 📚 About This Repository

This repository contains my work for the **Machine Learning Lab** course during **Fall 2026**.

The main purpose of this repository is to document my practical learning journey in Machine Learning, including:

- Data preprocessing
- Data cleaning
- Exploratory Data Analysis (EDA)
- Data visualization
- Feature engineering
- Classification
- Regression
- Model training
- Model evaluation
- Hyperparameter tuning
- Model comparison
- Machine Learning projects
- Practical experiments using Python and Scikit-learn

The repository will be continuously updated throughout the semester as new laboratory tasks and projects are completed.

Through these laboratory exercises, I aim to develop practical skills in:

- Understanding Machine Learning workflows
- Working with real-world datasets
- Cleaning and preparing data
- Performing Exploratory Data Analysis
- Creating meaningful visualizations
- Preparing features for Machine Learning models
- Training different Machine Learning algorithms
- Evaluating model performance

- Comparing different Machine Learning models
- Applying Machine Learning concepts to practical problems
