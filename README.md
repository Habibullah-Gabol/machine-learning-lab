## 📚 About This Repository

This repository contains my practical work for the **Machine Learning Lab** course during **Fall 2026**, as part of my BS Computer Science degree.

The primary purpose of this repository is to document my hands-on learning journey in Machine Learning, covering fundamental concepts, algorithms, data analysis techniques, model development, and practical experiments using Python and Scikit-learn.

It includes laboratory exercises from **Lab 01 to Lab 10**, with their implementations, datasets, visualizations, experiments, and results.

The repository will continue to be updated throughout the semester as new laboratory exercises and projects are completed.

## 🔬 Laboratory Highlights

### Lab 01 — Python, NumPy, Pandas & Matplotlib

Introduction to the Python ecosystem for Machine Learning:

- Python programming fundamentals
- NumPy arrays and numerical operations
- Pandas Series and DataFrames
- Data manipulation and analysis
- Matplotlib visualizations

### Lab 02 — Data Cleaning and EDA

Working with real-world datasets and preparing data for Machine Learning:

- Data inspection
- Handling missing values
- Data cleaning
- Exploratory Data Analysis
- Data visualization
- Feature preparation

### Lab 03 — Decision Tree

Implementing Decision Tree classification:

- Decision Tree algorithm
- Training and testing datasets
- Classification predictions
- Model accuracy
- Model evaluation

### Lab 04 — Improving and Comparing ML Models

Exploring techniques for improving Machine Learning models:

- Model comparison
- Model performance evaluation
- Improving predictive performance
- Understanding model behavior

### Lab 05 — Linear Regression

Understanding regression-based prediction:

- Linear Regression
- Model training
- Prediction
- Regression evaluation metrics
- Model performance analysis

### Lab 06 — Logistic Regression and KNN

Implementing two important classification algorithms:

- Logistic Regression
- Sigmoid function
- Classification probabilities
- K-Nearest Neighbors
- Distance-based classification
- Classification evaluation

### Lab 07 — Naive Bayes: Spam Detection & Sentiment Analysis

Applying probabilistic Machine Learning to text classification:

- Bayes' theorem
- Naive Bayes classifier
- Text preprocessing
- Spam detection
- Sentiment analysis
- Text classification

### Lab 08 — Support Vector Machine (SVM)

Exploring Support Vector Machines for classification:

- Hyperplanes and decision boundaries
- Support vectors
- Maximum margin classification
- Linear and nonlinear classification
- Kernel functions

### Lab 09 — Bias, Variance and Imbalanced Data

A practical investigation using the Stroke Prediction dataset.

Key concepts:

- Bias-variance trade-off
- Underfitting and overfitting
- Learning curves and validation curves
- Bootstrap sampling and prediction variance
- Class imbalance
- Accuracy limitations on imbalanced datasets
- ROC and Precision-Recall curves
- Decision threshold selection
- Random undersampling and oversampling
- SMOTE and class weighting
- Data leakage
- Label noise and feature noise
- Model selection for medical screening

### Lab 10 — K-Means Clustering

Practical implementation of unsupervised learning and clustering:

- K-Means clustering algorithm
- Centroid initialization
- Cluster assignment and updating
- Implementing K-Means from scratch
- Elbow method and inertia
- Silhouette score and silhouette analysis
- Cluster initialization and stability
- Random initialization and K-Means++
- Adjusted Rand Index (ARI)
- Feature scaling and distance calculations
- Outlier effects on clustering
- Customer segmentation and cluster profiling
